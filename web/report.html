Radios that sleep. Agents that earn the right to act.

Over 93 % of a network vendor's carbon footprint is the energy its products draw in the field; Ericsson has pledged to halve it by 2030. A risk-aware planner puts capacity radios to sleep at night on real live-network data and leads published methods from Ericsson, Nokia, Elisa and Parallel Wireless. AI agents reach it through MCP; each is behaviour-tested on the exact model it runs on (NetCrash), signed, logged in a public transparency log, and checked by rules proved with an SMT solver. The last hop runs on a real LTE stack, and the AI's own energy is measured.

    The agent’s report

    
        
    
      
    
    
    
  
    

  
    
    
    
      
    
        
    
          
    NetCrash: can this agent be trusted, on this model?
    
          
    Suite v2: 22 hostile tests on stand-in networks (real traffic, scripted faults and injected text), three runs each, a two-model judge panel for undecidable text. Verdicts from actions first. Score = pass rate over decided runs; coverage = decided ÷ applicable. No pair reaches the admission bar (90, no failed test); every careful-prompt model split a change to slip under human approval.
    
        
    
      
    
      
    
      
    
      
    
    
    
  
    

  
    
    
    
      
    
        
    
          
    Narrow the interface, not the prompt
    
          
    The same model through three interfaces: full (free-form propose / apply / rollback), constrained (one tool that can only keep cells awake in the planner’s plan) and workflow (one tool-less call that turns calendar and alarm text into typed events; code acts and writes the report). Each step removes a class of failure: approval gaming, then loops, leaks and false “all clear”.
    
        
    
      
    
      
    
      
    “Model-decided” = tests whose outcome still depends on the model; the rest are prevented by the interface or decided by code and are not counted as passes. A workflow 100 says the system held; it says little about the model (findings E38–E40, decisions D45–D46).
    
    
    
  
    

  
    
    
    
      
    Outside the simulator: real stack, measured energy, proofs
    
      
    
        
    Real LTE stacksrsRAN 4G (core, base station, phone) over a software radio: after an approved wake, user traffic flows again in 2.4 s median (worst 2.6 s, 10/10), 0.3 % of the quarter-hour the planner allows; the base station followed the arbiter’s schedule in 24 of 24 quarter-hours. Radio hardware and its power are not covered (E33).
    
        
    The AI’s own energyOne agent night on a local model (qwen3:4b, laptop RTX 4050), GPU sampled every 100 ms: 7.6 Wh against 21.3 kWh saved, 0.035 % (E36).
    
        
    Proved rulesNine arbiter invariants, property-tested; the capacity rule proved with Z3 for every sleep state under the stated forecast assumption, with a counterexample when the assumption is dropped (E28).
    
        
    Signed identityEvery MCP request carries an RFC 9421 signature from a key bound by the operator to one Agent Card and one model; tools outside the card are refused (E35).
    
        
    Public log21 NetCrash scorecards in Sigstore Rekor with verified inclusion proofs and signed timestamps (index; E34).
    
      
    
    
    
  
    

  
    
    
    
      
    
        
    
          
    The attestation admit() checks
    
          
    An in-toto Test Result statement in a DSSE envelope, signed with Ed25519. Its subject is the agent’s Agent Card hash, which covers the exact prompt; change one word and the attestation no longer applies. Compatible with agent-trust-kit.
